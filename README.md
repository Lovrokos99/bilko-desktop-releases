# Bilko Računovodstvo: namestitvene datoteke

Ta javni repozitorij vsebuje samo namestitvene datoteke namiznega programa **Bilko Računovodstvo**
(za Windows) in datoteko `latest.json`, iz katere nameščeni program sam preverja posodobitve.

**Prenos (vedno najnovejša različica):** https://github.com/Lovrokos99/bilko-desktop-releases/raw/main/Bilko-Racunovodstvo-setup.exe

Trenutna različica: **0.1.0** (objavljena 2026-10-14).

Ob prvi namestitvi lahko Windows pokaže opozorilo SmartScreen: klikni *Več informacij* in nato
*Vseeno zaženi*. Poznejše posodobitve program prenese in namesti sam.

Datoteke v tem repozitoriju objavlja samodejna gradnja; ročno jih ne spreminjaj.
